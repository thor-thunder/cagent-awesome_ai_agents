Welcome to the **Ultimate Hub for AI Agents**, your one-stop destination for all things related to AI-driven agents. Whether you're a researcher, developer, or enthusiast, this repository brings together the most advanced tools, resources, and inspiring projects in the world of AI agents.

This repository is a comprehensive hub for resources related to AI agents, providing a curated collection of tools, frameworks, datasets, and projects. It offers daily updates on the latest advancements in AI and machine learning agents.

Here are some ways you can use this repository:

- **Explore** - Browse through the different sections to find tools, resources, and projects that match your interests and needs (e.g. to use, learn, or build agents).
- **Contribute** - Share your own projects, tools, or resources related to AI agents and contribute to the growing body of knowledge in this field.

## Where to find things

The substantive content of this repository is split across three companion files:

- **[SKILL.md](./SKILL.md)** — the curated lists themselves (Using → Applications; Learning → Repositories, Courses; Building → Benchmarks, Datasets, Deployment, Ethics, Frameworks, LLM Models, Prompt Engineering, Security, Testing, Tools, Workflows) plus the maintainer skill that describes how to add or update an entry.
- **[REFERENCES.md](./REFERENCES.md)** — the upcoming Agents Connect conference, the contributors roll (PR + issue contributors), sharing copy for LinkedIn and Twitter, and the license note.
- **[CLAUDE.md](./CLAUDE.md)** — operating instructions for an AI assistant working in this repo: entry conventions, where new entries go, contributor and version rules.

## Contributing

💡 Contributions are welcome!

Feel free to submit a pull request, suggest a new resource, or [open an issue](https://github.com/jim-schwoebel/awesome_ai_agents/issues/new).

Make sure your submissions align with the following guidelines:

- Relevance to AI agents (e.g. category — using agents, learning agents, building agents)
- Clear documentation and accessibility (e.g. name + link + 1 sentence description)

Pick the matching category in [SKILL.md](./SKILL.md), insert your entry alphabetically in the standard `- [Name](url) - One-sentence description.` format, and add yourself to the contributors list in [REFERENCES.md](./REFERENCES.md).
